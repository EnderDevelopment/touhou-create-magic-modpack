# Touhou and Create and Magic Modpack which is chill

This Minecraft modpack combines the magical elements of Touhou Project with the creative building possibilities of Create and Magic. It offers a unique blend of fantasy and creativity, allowing players to explore a world filled with magical creatures, spells, and structures.

## Install

1. Download the modpack from the GitHub repository.
2. Install the required dependencies: Minecraft Forge, Create Mod, and Magic Mod.
3. Extract the modpack files to your Minecraft directory.
4. Launch Minecraft and select the modpack profile.

## Use

1. Launch Minecraft and select the modpack profile.
2. Explore the world and interact with magical creatures and structures.
3. Use the Create Mod tools to build and create your own structures.
4. Cast spells and use magical items to enhance your gameplay experience.
